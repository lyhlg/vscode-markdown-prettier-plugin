# Welcome to Markdown Prettier

This extension renders markdown with improved readability.

## Features

### Colored Headings

H1, H2, and H3 are displayed in different colors:

- **H1** — Blue (#61AFEF)
- **H2** — Green (#98C379)
- **H3** — Yellow (#E5C07B)

### TOC Sidebar

Click a heading in the left sidebar to scroll to that section.

### Code Blocks

```javascript
function hello() {
  console.log("Hello, Markdown Prettier!");
}
```
